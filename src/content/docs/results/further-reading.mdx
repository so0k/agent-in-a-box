## What to remember

- Box's own pages are on GitHub and describe the current `main` branch, which can be newer than this workshop's build.
- For the policy language, start with Box's policy guide, then Cedar's syntax and authorization pages.
- For code mode, Cloudflare's two blog posts explain the design; Box's MCP pages explain what Box can see of it.
- Claude Code and OpenCode now offer a code mode of their own, on the developer's side; neither was run here.
