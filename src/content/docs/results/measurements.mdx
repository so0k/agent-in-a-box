This page holds every number the workshop quotes: tokens, cost, turns and time for each act and task, and the build of Box each was measured on, with the earlier runs kept as a comparison. After it you will know what each set-up costs the developer, how much of that is the tool list, and how far the numbers can be compared. The story needs it last because the acts traded control against cost, and this is the cost side, measured.

<Pieces stage={5} />

The picture is the final one. The numbers below belong to its different paths: the token-scope act without the box, the next four acts through the vendor's MCP server, and the request-rules act through the local exec proxy.

## How to read these numbers

- **One run per cell.** Each row is one run, with model `claude-sonnet-5-5`, a plain task and no adversarial prompting. A second run of the same task can differ; where a repeat exists, it is shown.
- **Claude Code's own figures.** Turns, tokens and cost are what Claude Code reported at the end of the run, in its `result` event. Box's records hold no token or byte figures.
- **Input tokens** are all kinds added: uncached, cache write and cache read. The three parts are shown in brackets.
- **Time** is two numbers: Claude Code's own duration, and the wall time of the whole command.
- **Tool loading** says what the model was given. "Code mode" is the vendor's server with a handful of tools, run with `--tools ""`, so Claude Code's tool search was off. "Per-endpoint" is the vendor's 3,053 tools with tool search on (`--tools ToolSearch`), so the model receives only the tool names and loads a definition when it needs one. "Exec proxy" is the local server's two tools, tool search off.
- **Builds.** The workshop's steps use the released **Box 0.3.0** for the token-scope (no box), opaque-execute, deny-execute and request-rules acts, and for Part 4 the **fork build** of the branch `bugfix/mcp-shared-definitions` at commit `535307a` (it prints `box 0.1.0`). Every boxed run used the Claude Code pack. [Builds and gaps](/results/builds-and-gaps/) says what each build is.
- **Earlier runs, kept as a comparison.** The groups under [Earlier: the hand-written profile on local builds](#earlier-the-hand-written-profile-on-local-builds) were measured before the release, with a hand-written profile (no pack system prompt), on local builds (pkg-fix, pkg, pkg-main) and the installed releases box 0.1.8 and 0.1.11.
- **Do not compare across groups as if only Box changed.** The groups also differ in Claude Code version (2.1.325, 2.1.326, 2.1.330, 2.1.331), in the profile, and in the policy files: the 2026-11-24 runs and the pkg-fix runs of the deny-execute and request-rules acts used the files you write in this workshop; the other earlier runs used policies generated by the author's kit (now in the `kit/` folder of [box-exec-proxy](https://github.com/so0k/box-exec-proxy)), so their refusals name other rule ids.
- **Outcome "logs returned"** means log lines came back. In the earlier runs the last hour of the Worker's logs held only two request lines; the attendee events with email addresses were older. An email came back in one run: the token-scope act with a 24-hour window (redacted in the evidence). In the 2026-11-24 runs the last hour held no events, so the outcome there is "query ran, 0 events".

Sources: the result files of each run, in the author's measurement notes (not published), and Claude Code's own result figures of the runs made while writing and verifying this workshop. Every number on this page was copied from one of those; none is estimated, except where a line says it was computed.

## What the pack changed in the numbers

- **About 3,500 more input tokens per boxed run:** the pack's system prompt, `box.md`, and one line naming the profile ([Inside the pack](/part-2/inside-the-pack/#the-system-prompt)). The allowed task had 6,421 input tokens with no box and 9,900 in the opaque-execute act.
- **The cheap tasks roughly doubled in cost:** in code mode and through the exec proxy, the allowed tasks went from USD 0.0114 (opaque-execute, box 0.1.8) and 0.0140 (request-rules, pkg-fix) to 0.0229 and 0.0215.
- **Part 4 sits at its cap:** the per-endpoint runs cost USD 0.2201 to 0.2537, and one of four went over 0.25. The Part 4 pages now carry a cap of 0.40.
- **The token-scope act rose too** (3,981 to 6,421 input tokens for the allowed task, 21,563 to 100,744 for the logs task). That is not the pack: this act has no box. Claude Code moved from 2.1.325 to 2.1.331, and there was one run each, so the cause is not established.

## Where the tokens go: the tool list

Most of the tool-allowlist act's cost is the tool list. These figures come from Anthropic's token-counting endpoint for `claude-sonnet-5-5`, with the tools named as Claude Code names them. They were measured on 2026-11-14, when the per-endpoint catalog had 11 tools fewer than the 3,053 it had on 2026-11-21, and the larger list was not counted again. The numbers differ by more than a thousand times, so they are a table, not a chart.

| Tool list | Tokens | How measured |
|---|---|---|
| Exec proxy, 2 tools | about 1,500 | an estimate: 6,071 bytes divided by four, not counted |
| Vendor code mode, 4 tools | 3,510 | counted |
| Vendor per-endpoint, names only (what tool search sends) | 75,349 | counted, on the list of 2026-11-14 |
| Vendor per-endpoint, every definition | 2,382,210 | counted, on the list of 2026-11-14 |

What a run actually sent, measured: the first model request of the request-rules act was 2,263 input tokens in all (box 0.1.8 run). The first request of the tool-allowlist act, with tool search on, was about 78,600 input tokens, and each later turn read those names from the cache again, which is why every tool-allowlist run came to about 240,000 on the earlier builds (about 250,000 on 2026-11-24, with the pack's system prompt).

## The perspectives

<Seat who="security">

- Control did not have to cost money. The request-rules act's logs run, refused at the gateway, cost USD 0.0213 on Box 0.3.0; the uncontrolled token-scope run, without a box, cost USD 0.0756. One run each of different set-ups, so read it as the same order of size or less, not as a saving.
- Refusing `execute` by name was cheap too (USD 0.0098 for the allowed task), but it refused the harmless task.
- Per-operation control through the vendor's catalog cost much more per run: for the allowed task 12.0 times the token-scope act and 10.5 times the request-rules act (computed from one run each on 2026-11-24; 7 to 14 times on box 0.1.8), and a minute of waiting on every run, whether or not anything was refused.
- These are single runs of plain tasks. They say nothing about a model that tries to get around a rule.

</Seat>
<Seat who="developer">

- The request-rules act is the cheapest working boxed set-up measured: 8,300 input tokens and USD 0.0215 for the allowed task on Box 0.3.0, in 2 turns and 8.3 seconds.
- The per-endpoint catalog sends about 75,000 tokens of tool names on every request, even with tool search, and waits about a minute before the first turn. Turning tool search off does not help: the request is too large for the model.
- A refusal costs turns. The deny-execute act's logs task spent 4 turns and 22,816 input tokens before it reached the refused `execute`; the request-rules act's spent 4 turns and 20,561.

</Seat>

## What to remember

- The workshop's steps use Box 0.3.0, and the fork build at 535307a for Part 4; every act was measured on them on 2026-11-24, one run each. The earlier groups are kept as a comparison, and every number here says its build.
- Code mode and the exec proxy cost a few thousand to about a hundred thousand input tokens a run; the per-endpoint catalog about 250,000.
- The pack's system prompt adds about 3,500 input tokens to every boxed run.
- Most of the per-endpoint cost is the tool names, sent on every request.
- On the builds that accept it, the per-endpoint catalog adds a wait of about a minute before the agent has its tools.
